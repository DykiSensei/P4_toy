# 自然手帐首页与页面切换

日期：2026-11-09。范围：用户确认自然手帐设计后，先实现基础界面并烧录。

## 当前行为

上电显示暖白底、深绿拍照卡片的“小小探索家”首页。首页可进入拍照发现、探索地图、我的图鉴、伙伴对战；右上进入设置。各页面左上返回首页，底部按钮按文案跳转。设置提供重新校准、界面说明和返回首页。

这版没有模拟已经成功的识别、定位、收藏或对战。取景区使用示意植物，图鉴显示零收藏，地图没有虚构位置和路线，伙伴连接显示尚未接入。电源栏显示 USB 供电，不显示未经测量的电量百分比。

## 触摸

- XPT2046，电阻触摸；GPIO46/47/48/49/50 分别为 CLK/CS/DIN/DO/IRQ，IRQ 低有效。
- 独立 GPIO 时序，不占用 LCD 的 SPI2。原始 12 位数据先去极值、双组过滤，再由应用做按压与释放消抖。
- 没有校准记录时，首页第一次有效点击进入校准。依次按左上、右上、右下、左下十字中心，每次约半秒并松开。
- 前三点建立仿射映射，支持交换轴和反向轴；第四点独立检查，误差超过 20 px 就重做，避免保存错误映射。
- 校准成功保存在 NVS 的 `nature_ui/touch_v1`。NVS 故障时不擦除旧分区；当前会话仍可使用校准，日志注明不能持久保存。
- 设置的“重新校准”可重做。若坐标已经不准，在任意页面按住屏幕 3 秒即可进入校准，不依赖旧的坐标映射；先松手，再按第一个目标。触发长按的那次按压不会被误算成第一个校准点。校准过程中同样可长按重新开始。
- 新校准通过四点检查后才替换旧记录；重做失败不会覆盖之前保存的结果。尚未校准时也可通过串口检查显示。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `main/lcd_bringup.c` / `lcd_display.h` | 沿用已验证 ST7796S 初始化、LDO4=3300mV 与 10MHz SPI；提供条带写入 |
| `main/ui_canvas.c` / `.h` | 160 条绘图指令、8 行 RGB565 缓冲，圆角、线条、椭圆、中文文字 |
| `main/ui_pages.c` / `.h` | 首页、四个入口页、设置、说明与校准目标；点击区域 |
| `main/ui_app.c` | 页面切换、触摸消抖、仿射校准、NVS、串口命令 |
| `main/touch_input.c` / `.h` | XPT2046 原始采样，不硬编码屏幕方向 |
| `main/ui_font_data.c` | 常量中文字库，驻留 Flash |
| `tools/generate_ui_font.py` | 从界面源文件提取字形，生成 Noto Sans SC 子集 |
| `tools/ui_console.py` | 读取串口日志、发送本地页面快捷键 |

字形源为本机 Noto Sans SC，13/16/18/20/24/26 px，4 位灰度覆盖，许可见 [FONT_LICENSE.txt](FONT_LICENSE.txt)。修改页面文案后先运行 `python tools/generate_ui_font.py`，再用 ESP-IDF 构建。

暂不引入完整 UI 框架；此次先用有限内存验证已确认的视觉和输入。图片、地图、业务状态及更复杂控件接入后，再根据资源预算决定框架。静态页面只在切换时重绘，不持续刷屏；后续动画与动态数据应采用局部更新。

## 验证与恢复

- 本机使用同一套 C 绘图代码渲染全部 7 页和 4 个校准目标；导航、返回和相邻按钮间隙检查通过。
- ESP-IDF 构建通过，加入长按重校后的应用 610,464 字节，默认 1 MiB 应用分区剩余约 42%。
- COM12 烧录成功，bootloader、分区表、应用均通过 hash 校验。
- 串口逐页切换验证：282–358 ms/次，可用内部堆 559,208 字节；没有观察到崩溃或看门狗复位。该值是当前静态页面的测量，不代表未来地图或摄像头性能。
- 用户已确认实屏显示、首次校准和页面切换均正常。长按重新校准是此确认后按用户追加要求增加的恢复方式。
- 重新校准更新已烧录；重启后串口 `calibrated=1`，确认之前的校准记录可持久读取，首页刷新约 357 ms。
- 上一版点屏源码和应用保存在 `backups/before_home_ui/`，可用于恢复对照。原始整片 Flash 备份保留在 `backups/before_lcd_bringup_16MB.bin`。

日志位于 `build/flash_ui.log`、`build/monitor_ui_navigation.log`、`build/monitor_ui_touch.log`；重校更新日志为 `build/flash_ui_recalibrate.log` 和 `build/monitor_ui_recalibrate.log`。
