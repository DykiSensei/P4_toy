# WTDKP4C5-S1 GPIO 分配表

更新日期：2026-11-09  
适用项目：P4 儿童自然探索玩具，当前 ST7796S 屏幕与 XPT2046 触摸接线  
核对基准：WT01P4C5-S1 核心板规格书 V1.3、WTDKP4C5-S1-1V3 开发板原理图 V1.1、当前项目固件

本表区分芯片供电域、核心板内部连接、开发板接口及项目实际占用。P4 表覆盖 GPIO0–54；C5 另列核心板对外引出的 GPIO。表中的“候选”表示当前资料和固件未显示占用，接入新模块前仍需核对实物板版本、供电和外设要求。

## 1 编号与状态说明

- **GPIO 编号**：芯片的软件编号。`P4 GPIO7` 和 `C5 GPIO7` 属于不同芯片，不能混用。
- **核心板脚**：WT01P4C5-S1 模块的 92 脚编号，不是 ESP32 芯片封装脚号。
- **开发板脚位**：例如 `J3-36` 表示底板 J3 连接器的第 36 脚；接线时按实物 1 脚标记和原理图编号定位。
- **已用／已接**：当前程序使用或已实际接线；即使某模块驱动尚未启用，已接线也属于占用。
- **板内占用**：模块内部已经连接到另一芯片，不能当作独立外接资源。
- **预留**：为板载接口、调试、启动配置或计划中的摄像头保留。
- **候选／条件候选**：当前未分配，条件候选需要先确认是否采用表中列出的其它用途。

芯片支持 SPI、I²C、UART 等复用功能，不代表这些功能已在板上连接。例如当前 SPI2 使用 GPIO39、42、43、45，不会因此同时占用 GPIO28–33。

## 2 P4 供电域

| P4 GPIO 范围 | 芯片 I/O 供电域 | 本项目需要注意的供电关系 |
| --- | --- | --- |
| GPIO0–3 | VDD_LP / VDD_BAT | 供电选择与芯片工作模式有关；模块外部 VBAT 脚在本版规格中标为 NC，不能直接按芯片 VBAT 功能使用 |
| GPIO4–15 | VDD_LP | 由模块内部供电；GPIO12–15 虽在此域，已有 C5 内部连接 |
| GPIO16–23 | VDD_IO_0 | 由模块内部供电；GPIO16–19 已用于 C5 SDIO |
| GPIO24–38 | VDD_IO_4 | 包含 USB Serial/JTAG、UART0 与启动配置脚 |
| GPIO39–48 | VDD_IO_5 | 当前板上依赖 LDO4 供电；配置 GPIO 前先申请通道 4、3300mV，并在使用期间保持申请 |
| GPIO49–54 | VDD_IO_6 | 与 GPIO39–48 不同域，不应归入 LDO4 管理范围 |

供电域分组依据乐鑫 [P4 引脚供电表](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32p4/schematic-checklist-esp32p4.html#gpio)。`VDD_IO_4` 是电源域名称，**不等于 LDO4**；本项目与 LDO4 关联的是 `VDD_IO_5`。

LDO4 与 GPIO39–48 的关系有本项目实机对照记录；其它域的模块内部电源连线和电压未逐一实测。本表给出供电域归属，不将芯片允许电压范围当成可随意改变的板级供电方案。屏幕 VCC 的 5V 供电独立于 GPIO 信号供电，信号引脚不得接 5V。初始化及实测见 [README](../README.md#必须保留的板级供电初始化)。

## 5 C5 对外引出的 GPIO

C5 是独立芯片。以下引脚由 C5 固件控制，不能直接作为 P4 的 `gpio_num` 使用。当前 P4 应用未启用 C5 网络功能，但本次未读取 C5 实际固件，因此“未分配”仅指本项目尚未安排新的用途。

C5 模块脚位依据核心板规格书第 10、13、14 页；供电域依据 [ESP32-C5 Datasheet v1.5](https://www.espressif.com/sites/default/files/documentation/esp32-c5_datasheet_en.pdf) 第 19–20 页表 2-1，启动约束见第 33 页。VDDPST1、2、3 是 C5 自己的电源域，与 P4 同名序号无对应关系；模块内部实际供电仍以板级设计为准。

按本版原理图，SW2 的 BOOT 网络同时经 R48 接 P4 GPIO35、经 R46 接 C5 GPIO28，两电阻均标为 0Ω；SW1 通过 R47 连接 P4_EN，通往 C5_EN 的 R45 标为 NC。实物焊装与版本差异需在改动启动电路前核对。

J7、J8 调试连接器在图纸中标为 NC，实际是否焊装需看实物；其脚号均为：1=GND、2=BOOT、3=EN、4=RX、5=TX、6=NC、7=5V。NC 标记不取消相关网络在其它排针上的预留用途。

## 7 可分配资源与冲突

保持当前屏幕、触摸接线及摄像头、启动、调试预留时，P4 有以下 **21 个优先评估候选**：

`0、1、2、3、4、6、9、10、11、20、21、22、23、28、29、30、31、32、33、51、52`

GPIO26、27 另列 2 个条件候选。GPIO34 仍作为启动配置脚保留，未加入上述清单。候选清单不等于已为 GPS、SD 卡或按键指定接线；下一步按模块电压、所需总线和实际布线选取。

- **屏幕与 SD1**：GPIO39–48 同时具有固定 SD1 引脚功能，当前已接屏幕和触摸。后续存储不能直接沿用这组脚接 SD 卡；应评估其它可路由接口方案或重新安排接线。
- **C5 通信**：P4 GPIO12–19 虽然当前应用未启用对应功能，模块内部连线已经存在，应保留。
- **摄像头**：先保留 GPIO7、8 的共享 I²C 及 GPIO53、54 的控制线，避免为 GPS 或按键提前占用。
- **启动与恢复**：GPIO34–38 先保留，避免新增外部上拉、下拉或驱动影响启动和烧录恢复。
- **供电生命周期**：显示和触摸使用期间保持 LDO4 申请；未来休眠及电源管理必须把这一依赖纳入设计。

本版底板原理图未显示已接入的 SD 卡槽；厂家 BSP 中 SD 引脚为 NC，不能将芯片的 SD 控制器能力当作现成板载存储接口。

## 8 资料差异与维护规则

1. [厂家功能页](https://wiki.wireless-tag.com/docs/zh/WTDKP4C5-S1/board_features.html) 的 J3 表没有物理脚号，且 RXD 后多出一个 GND 条目。按网页行序推导编号会错位；本表采用原理图编号，例如 GPIO38=J3-9、GPIO52=J3-10、GPIO39=J3-36。
2. 本版原理图和功能页使用 J2、J3、J4、J7、J8 等位号，未确认 J5。其它说明中的 J5 不直接套用到本板。
3. [厂家 BSP 头文件](https://github.com/wireless-tag-com/WTDKP4C5-S1/blob/master/components/wtdkp4c5_s1_board/include/bsp/wtdkp4c5_s1_board.h) 将 GPIO26、27 用于 DSI 背光和复位；这是示例配置，本表没有将其当成当前硬件占用。
4. 本次核对的 [厂家示例配置](https://github.com/wireless-tag-com/WTDKP4C5-S1/blob/master/sdkconfig.defaults) 将 GPIO54 设为 C5 复位脚，与核心板第 19 页所列 P4 GPIO13 内部复位连接及底板 CAM_IO1 分配不一致。接入无线前应核实示例版本与硬件，不能直接照搬该配置。
